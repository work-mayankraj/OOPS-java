## 1. Employee Management – Parameterized Constructor

**Question:**  
Create a Java program using a parameterized constructor to implement an `Employee` class with employee name, employee ID, and department as data members. Initialize these values through a constructor and create a `disp()` method to display the employee details. In the main class, create three employee objects using the parameterized constructor, assign details to the first two employees directly, accept the name of the third employee from the user using `Scanner`, and display the details of all three employees.
