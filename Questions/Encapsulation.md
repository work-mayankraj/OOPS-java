## 1. Bank Account – Encapsulation

**Question:**  
Create a Java program using encapsulation to implement a `BankAccount` class with private account number, account holder name, and balance. Provide setter and getter methods for these properties, ensuring that the balance cannot be negative. Also implement `deposit()` and `withdraw()` methods with appropriate validation, and create a main class to take account details and perform deposit and withdrawal operations.
